# 統合占いアプリ (fortune-telling app)

動物占い・四柱推命・西洋占星術・マヤ暦・算命学の5つの占術を、共通の暦計算エンジンの上でまとめて診断する React Native (Expo) アプリ。個人の統合分析と、2人の相性診断ができます。

## 構成

```
src/
  engine/         暦計算・各占術のロジック(純粋なTypeScript、UI非依存)
  types/          プロフィールなどの共有型
  storage/        AsyncStorageによるプロフィール保存
  navigation/     React Navigation (stack)
  screens/        画面コンポーネント
__tests__/engine/ エンジンのユニットテスト(jest)
```

### エンジンの設計

すべての占術は共通の暦計算プリミティブの上に構築されています。

- `julian.ts` - ユリウス日変換(Meeusの天文アルゴリズム)
- `solar.ts` / `lunar.ts` - 太陽・月の視黄経(低精度だが精度0.01〜0.3度程度)
- `sekki.ts` - 二十四節気の正確な瞬間を二分探索で算出
- `kanshi.ts` - 干支60周期の基礎データ、日柱の算出
- `shichuSuimei.ts` - 四柱推命(節入りベースの年柱・月柱、五虎遁・五鼠遁による月干・時干、十神、五行バランス)
- `sanmeigaku.ts` - 算命学(陰占、十大主星、十二大従星/十二運)
- `animalFortune.ts` - 動物占い(**独自実装**。日柱の十二支から動物、日干の五行からカラーを決定する60パターン。特定の市販サービスの非公開ロジック/テーブルを再現したものではありません)
- `astrology.ts` - 西洋占星術(太陽星座・月星座は実際の黄経計算、出生時刻・場所があればアセンダントも実際の地方恒星時から計算)
- `mayanCalendar.ts` - マヤ暦(GMT相関定数584283によるロングカウント、ツォルキン、ハアブ)
- `integrated.ts` - 5占術を統合した総合コメント生成
- `compatibility.ts` - 2人分の相性診断

### 暦計算の検証

`__tests__/engine/` に、外部で確認できる史実の日付を基準にしたテストがあります。

- 干支日: 1900-01-01 = 甲戌、2000-01-01 = 戊午
- マヤ暦: 2012-12-21 = ロングカウント 13.0.0.0.0 = 4 Ahau 3 Kankin(有名な「マヤ暦終末説」の基準日)
- 二十四節気: 立春が例年2/3〜2/5に収まること、夏至が6/20〜6/22に収まること
- 西洋占星術: 既知の太陽星座の日付、アセンダントの可換性

## 既知の制約・今後の拡張候補

- 西洋占星術は太陽・月・アセンダントのみ対応。水星〜冥王星やハウスは未実装(本格的な惑星暦計算が必要なため今後の拡張候補)。
- 動物占いは独自実装であり、特定の商用サービスと同じ結果になるとは限りません。
- マヤ暦の紋章・トーンのキーワードは新設紀(ドリームスペル系)でよく使われる解釈を採用しています。流派により解釈が異なる場合があります。
- 出生地はプリセットの主要都市から選択する方式です(緯度経度の直接入力・検索は未対応)。
- 日柱の日境界は伝統的な「23時開始(子の刻)」を採用しています(流派によっては正子0時を採用する場合もあります)。

## アプリの使い方

1. 「+ 新しく診断する」から生年月日(・時刻・出生地)を入力
2. 総合タブで5占術を統合したコメント、各タブで占術ごとの詳細を確認
3. 2人分のプロフィールを登録すると「相性を診断する」から相性診断が可能

## 開発

```bash
npm install
npm start        # Expo開発サーバー
npm run web       # ブラウザで確認
npm test
npm run typecheck
```
